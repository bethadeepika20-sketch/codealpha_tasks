
# Unemployment Analysis with Python

## Project Overview
This project analyzes the unemployment rate in the United States using Python. It explores unemployment trends over time and the distribution of unemployment rates using data visualization.

## Objectives
- Analyze unemployment rates over time.
- Identify the highest and lowest recorded rates.
- Understand the distribution of unemployment rates.
- Visualize data using graphs.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Files
- `unemployment_analysis.py` - Python analysis code
- `unemployment_trend.png` - Unemployment trend graph
- `unemployment_distribution.png` - Distribution graph

## Visualizations
The project includes:
1. Unemployment Rate Over Time
2. Distribution of Unemployment Rates

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib`
3. Run:
   `python unemployment_analysis.py`

## Data Source
Federal Reserve Bank of St. Louis (FRED), UNRATE series.

## Conclusion
This project demonstrates how Python can be used to explore unemployment data, summarize statistics, and create visualizations that help explain economic trends.
