
# Car Price Prediction with Python

## Project Overview
This project uses Machine Learning to predict car prices based on the car's manufacturing year, kilometers driven, and engine capacity.

## Objectives
- Explore car data.
- Train a machine learning model.
- Predict car prices.
- Compare actual and predicted prices.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Linear Regression

## Dataset
This beginner project uses a small, manually created sample dataset for demonstration and learning.

Features:
- Year
- Kilometers Driven
- Engine Capacity (CC)

Target:
- Price

## Machine Learning Workflow
1. Create and explore the dataset.
2. Separate features and target.
3. Split data into training and testing sets.
4. Train a Linear Regression model.
5. Predict car prices.
6. Evaluate predictions using MAE and R² score.
7. Visualize actual versus predicted prices.

## Project Files
- `car_price_prediction.py` - Python source code
- `car_price_prediction.png` - Actual versus predicted price graph
- `README.md` - Project documentation
- `requirements.txt` - Required libraries

## How to Run
Install the libraries:

`pip install -r requirements.txt`

Run the project:

`python car_price_prediction.py`

## Limitations
The model uses only 20 sample records. Its predictions are for demonstration and should not be treated as reliable real-world car valuations.

## Conclusion
This project demonstrates the basic workflow of building and evaluating a car price prediction model using Python and Linear Regression.
